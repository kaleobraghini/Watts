# Watts

Mostra em tempo real quantos watts estão entrando na bateria do celular, com gráfico dos
últimos 2 minutos, tensão, corrente, temperatura, fonte de carga e estatísticas da carga
(pico, média, energia em Wh). Sem internet, sem permissões, nada roda em segundo plano.

Para gerar uma versão nova: faça commit e crie uma tag `vX.Y.Z`. O APK sai em Releases.
